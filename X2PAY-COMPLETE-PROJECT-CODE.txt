================================================================================
API ENDPOINTS
================================================================================

x402 PAYMENTS:
- POST /api/x402/requirements  - Generate payment requirements
- POST /api/x402/verify        - Verify payment
- POST /api/x402/settle        - Settle payment

AUTO-BUY & BURN:
- POST /api/auto-buy/start     - Start auto-buy
- POST /api/auto-buy/stop      - Stop auto-buy
- GET  /api/auto-buy/status    - Get status

HARDWARE BRIDGE:
- GET  /api/hardware/bridge-status  - Check bridge status
- GET  /api/hardware/devices        - List devices
- POST /api/hardware/discover       - Discover devices
- POST /api/hardware/:deviceId/payment - Process payment

HEALTH:
- GET  /api/health             - Health check
- GET  /                       - Portal UI

DEPLOYMENT
================================================================================

VERCEL (Recommended):

  1. docker build -t x2pay .
  2. docker run -p 3000:3000 --env-file .env x2pay

PM2:
  1. npm run build
  2. pm2 start ecosystem.config.js

   npm install

   # Edit .env with your credentials

4. Start development server:
   npm run dev

5. Access portal:
   http://localhost:3000
