## **🚀 Deploy with Vercel (2 Minutes)**

### **Step 1: Install Vercel**
```powershell
npm install -g vercel
```

### **Step 2: Deploy**
```powershell
vercel
```

### **Step 3: Follow Prompts**
- Set up and deploy? → **Y**
- Which scope? → **Your account**  
- Link to existing? → **N**
- Project name? → **x4pay-portal** (or any name)
- Override settings? → **N**

### **Step 4: Done!**
You'll get a URL like: `https://x4pay-portal.vercel.app`

**Your portal is now live on the internet!** 🎉
