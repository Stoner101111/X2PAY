## ⚡ 3-MINUTE SETUP

### 1️⃣ SET YOUR TOKEN ADDRESS (REQUIRED!)

Open `.env` file and add your token mint address:

```bash
TOKEN_MINT_ADDRESS=YourTokenMintAddressHere
```

### 2️⃣ ENSURE SERVER IS RUNNING

Check if server is running at: **http://localhost:3000**

If not running:
```bash
npm start
```

### 3️⃣ ENABLE AUTO-BUY (OPTIONAL)

In `.env` file, change:
```bash
AUTO_BUY_ENABLED=true
```

Then restart:
```bash
# Press Ctrl+C, then:
npm start
```
