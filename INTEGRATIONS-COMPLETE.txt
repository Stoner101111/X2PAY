📚 INTEGRATION DETAILS:
--------------------------------------------------------------------------------

BLE SERVICE UUIDs (Nordic UART):
- Service: 6e400002-b5a3-f393-e0a9-e50e24dcca9e
- TX Char: 6e400003-b5a3-f393-e0a9-e50e24dcca9e
- RX Char: 6e400004-b5a3-f393-e0a9-e50e24dcca9e

Payment Flow:
1. Device advertises BLE
2. App scans and connects
3. App requests [CONFIG]
4. Device sends 402:// JSON
5. User selects options
6. App signs payment with x402
7. App sends X-PAYMENT:START
8. Device verifies via HTTPS
9. Device activates

Commands:
- [LOGO] - Request device logo
- [CONFIG] - Request payment config
- X-PAYMENT:START{...} - Start payment

Protocol:
- Device → App: 402://{...}
- App → Device: X-PAYMENT:START{...}
