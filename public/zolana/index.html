Architecture, Optimized for Amplify & Edge

Inspired by the ZPay roadmap, ZOLANA keeps the same crystal-clear separation of concerns—frontend experience, session orchestration, lightweight persistence, and programmable settlement.

Session Core

Express + TypeScript API that mints session IDs, emits unique Zcash shielded addresses, schedules expiry, and streams updates over Server Sent Events for real-time dashboards.

Zcash Detection

Polls lightwalletd or zcashd RPC via Upstash-friendly workers, verifying shielded deposits with configurable confirmation thresholds before promoting sessions to settlement.

Programmable Execution

Hands off confirmed sessions to Flashift’s createTransaction API, routes liquidity to Solana actions, and logs order IDs, deposit addresses, and final signatures.

Merchant Experience

Upstash REST snapshots, webhook callbacks, and SSE power a dashboard that keeps merchants in sync with every milestone—detected, confirmed, executed.

Bridge Flow

Payment Flow — ZCash → Solana

Every session inherits the battle-tested lifecycle shipped in the original ZPay blueprint while giving it a fresh autonomous face. All timing, retries, and status checks stay configurable.

  • 1. Session Creation Merchant requests /api/zpay/sessions with amount, target action, and metadata. ZOLANA responds with a unique shielded address, QR-ready payload, and expiration window.
  • 2. Detection & Confirmation Background workers poll Zcash RPC, track confirmations, and save state to Upstash to ensure Amplify cron jobs can resume seamlessly.
  • 3. Flashift Settlement Once confirmed, ZOLANA kicks off Flashift settlement, pushing SOL, tokens, or custom instructions to the destination wallet.
  • 4. Merchant Feedback Real-time SSE streams update merchant dashboards, and optional webhooks (HMAC signed) ping backend services the moment funds land.

Key Environment Vars

Wire up the same configuration surface as ZPay for production parity:

  • ZCASH_RPC_URL · lightwalletd or full node endpoint
  • FLASHIFT_API_KEY · Settlement provider secret
  • UPSTASH_REDIS_REST_URL · Optional session persistence
  • MERCHANT_WEBHOOK_URL · Notify downstream services
