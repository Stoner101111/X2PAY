## **Ready to Go Live?**

Your x4Pay portal is ready to deploy! Choose a platform below.

## **⚡ Vercel (Recommended - Free & Fast)**

### **Via CLI (2 minutes)**
```bash
# Install Vercel CLI
npm install -g vercel

# Deploy
cd c:\Users\Admin\solana-trading-agent
vercel

# Follow prompts, get your URL!
```

### **Via Website**
1. Push code to GitHub
2. Visit https://vercel.com
3. "New Project" → Import GitHub repo
4. Click "Deploy"
5. Get public URL!

---

## **🌐 Netlify**

```bash
npm install -g netlify-cli
netlify login
netlify deploy --prod
```

## **🔄 Render**

3. Connect GitHub

## **⚙️ Environment Variables**

Set these in your hosting platform:

```bash
NODE_ENV=production
PORT=3000
SOLANA_RPC_URL=https://api.mainnet-beta.solana.com
```

**Optional:**
```bash
SOLANA_PRIVATE_KEY=...
PUMP_API_KEY=...
TOKEN_MINT_ADDRESS=...
```
